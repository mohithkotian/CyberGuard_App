Guidelines
- Display interface icons at 20-24px; brand marks at 32px or larger.
- Keep icon labels visible for primary navigation.
- Do not add gradients, glow, or emoji alongside these icons.
- Decorative icons should use alt=""; meaningful standalone icons require an accessible label.
