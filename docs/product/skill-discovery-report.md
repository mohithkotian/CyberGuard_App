## New Capability Discovered

> **New capability discovered: API Contract Documentation (OpenAPI/Swagger)**
>
> **Source:** Custom skill — no existing trusted registry skill covers Express + swagger-jsdoc. Pattern is well-established via `swagger-jsdoc` + `swagger-ui-express` (both MIT, actively maintained).
>
> **Why it matters for CyberGuard:** The backend has 9 Express route files consumed by three clients (React web app, Expo mobile, Python ML service). Currently there is no machine-readable contract between them. Adding a skill that guides Claude to annotate routes with JSDoc comments and generate a live Swagger UI at `/api-docs` would: (1) catch integration bugs early, (2) give the mobile team a self-service reference, (3) make the API auditable for security review. The domain handles sensitive citizen data — undocumented endpoints are a security risk as well as a development friction.
>
> **Confidence:** High — the gap is real, the solution is proven, the libraries are MIT.
> **License:** MIT (swagger-jsdoc, swagger-ui-express)
