## Required .env Files

### backend/.env

Create `backend/.env` with the following (fill in your real secrets):

```env
# Server
NODE_ENV=development
PORT=5002

# MongoDB
MONGODB_URI=mongodb://localhost:27017/cybercrime_db

# JWT — generate strong random strings (min 64 chars each)
JWT_SECRET=replace-this-with-64-random-characters-abcdef1234567890
JWT_EXPIRES_IN=7d
JWT_REFRESH_SECRET=another-64-random-characters-different-from-above-xyz
JWT_REFRESH_EXPIRES_IN=30d

# ML Service
ML_SERVICE_URL=http://127.0.0.1:5001
ML_SERVICE_TIMEOUT=10000

# Admin seed credentials (created automatically on first run)
ADMIN_EMAIL=admin@cybercrime.gov
ADMIN_PASSWORD=Admin@123456

# File upload
MAX_FILE_SIZE=10485760
UPLOAD_PATH=./uploads

# Rate limiting
RATE_LIMIT_WINDOW=15
RATE_LIMIT_MAX=100

# CORS
ALLOWED_ORIGINS=http://localhost:3000,http://localhost:19006

# AI APIs (leave empty to disable gracefully)
GEMINI_API_KEY=your-google-gemini-api-key-here
ELEVENLABS_API_KEY=your-elevenlabs-key-here

# Email (Gmail SMTP with App Password)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-gmail@gmail.com
SMTP_PASS=your-gmail-app-password

# Twilio SMS (leave empty or omit to disable)
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your-twilio-auth-token
TWILIO_MESSAGING_SERVICE_SID=MGxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

> **Note:** Twilio SID must start with `AC`. If not configured, SMS is gracefully disabled.

## Starting Each Service

### Step 1 — MongoDB

MongoDB must be started first.

**Check if already running (Windows service):**
```powershell
Get-Service -Name "MongoDB"
```

**Start if stopped:**
```powershell
Start-Service -Name "MongoDB"
```

**If not installed as a service, run manually:**
```powershell
mongod --dbpath "C:\data\db"
```

MongoDB will listen on port **27017**.

---

### Step 2 — ML Service (Python Flask, port 5001)

**First-time setup (one-time only):**
```powershell
# Install Python dependencies
pip install flask flask-cors scikit-learn nltk pandas numpy joblib scipy python-dotenv

# Download NLTK data
python -c "import nltk; [nltk.download(p) for p in ['punkt_tab','punkt','stopwords','wordnet','averaged_perceptron_tagger','averaged_perceptron_tagger_eng']]"

# Train the ML model (generates models/classifier.pkl)
cd ml-service
$env:PYTHONIOENCODING="utf-8"
python train_model.py
```

**Start the service:**
```powershell
cd ml-service
$env:PYTHONIOENCODING="utf-8"
$env:PYTHONPATH="$PWD\src"
python src/app.py
```

**Verify:**
```powershell
Invoke-RestMethod http://127.0.0.1:5001/health
# Expected: { status: 'ok', model_loaded: True }
```

---

### Step 3 — Backend (Node.js + Express, port 5002)

**First-time setup (one-time only):**
```powershell
cd backend
npm install
```

**Start (development with auto-reload):**
```powershell
cd backend
npm run dev
```

**Start (production):**
```powershell
cd backend
npm start
```

**Verify:**
```powershell
# Should return 401 (auth required = backend is alive)
Invoke-WebRequest http://localhost:5002/api/auth/me
```

---

### Step 4 — Web App (React, port 3000)

**First-time setup (one-time only):**
```powershell
cd web-app
npm install
```

**Start:**
```powershell
cd web-app
npm start
```

Open: **http://localhost:3000**

## Common Errors & Fixes

### [ERROR] `Error: accountSid must start with AC`
**Cause:** `TWILIO_ACCOUNT_SID` is a placeholder value in `.env`.  
**Fix:** Either add a real Twilio SID starting with `AC`, or leave `TWILIO_ACCOUNT_SID=` empty. The app skips SMS gracefully.

---

### [ERROR] `MONGODB_URI is not defined`
**Cause:** `backend/.env` is missing or not in the `backend/` directory.  
**Fix:** Ensure the file is at `backend/.env` (not the root).

---

### [ERROR] `ModuleNotFoundError: No module named 'classifier'`
**Cause:** ML service started from the wrong directory (Flask reloader loses `src/` in PATH).  
**Fix:** Always start with:
```powershell
$env:PYTHONPATH="$PWD\src"; python src/app.py
```
from inside the `ml-service/` directory.

---

### [ERROR] `LookupError: Resource 'punkt_tab' not found`
**Cause:** NLTK data not downloaded.  
**Fix:**
```powershell
python -c "import nltk; nltk.download('punkt_tab'); nltk.download('stopwords'); nltk.download('wordnet')"
```

---

### [ERROR] `Model not loaded. Run train_model.py first.`
**Cause:** `ml-service/models/classifier.pkl` does not exist.  
**Fix:**
```powershell
cd ml-service
$env:PYTHONIOENCODING="utf-8"
python train_model.py
```

---

### [ERROR] Web app: `ECONNRESET` during `npm install`
**Cause:** Transient network drop during large dependency download.  
**Fix:** Retry with:
```powershell
npm install --prefer-offline --no-audit
```

---

### [ERROR] JARVIS returns `GEMINI_API_KEY is not configured`
**Cause:** `GEMINI_API_KEY` is empty in `backend/.env`.  
**Fix:** Add your Google Gemini API key:
1. Go to https://aistudio.google.com/app/apikey
2. Create a key and paste it: `GEMINI_API_KEY=AIza...`
3. Restart the backend.

---

### [ERROR] Admin seeding fails with `Invalid Indian phone number`
**Cause:** The default phone in database.js was `0000000000` (not a valid Indian number).  
**Status:** Already fixed in this repo — phone is now `9000000000`.

## Privacy Shield

All user messages pass through the Privacy Shield **before** being sent to Gemini.

**What it masks (15 categories):**

| Token | Example |
|-------|---------|
| `PERSON_1` | Mohith Kotian |
| `EMAIL_1` | mohith@gmail.com |
| `PHONE_1` | 9876543210 |
| `CITY_1` | Bangalore |
| `AADHAAR_1` | 2345 6789 0123 |
| `PAN_1` | ABCDE1234F |
| `CREDIT_CARD_1` | 4111 1111 1111 1111 |
| `BANK_ACCOUNT_1` | 123456789012 |
| `IFSC_1` | SBIN0001234 |
| `PASSPORT_1` | A1234567 |
| `IPV4_1` | 192.168.1.100 |
| `URL_1` | https://example.com |
| `ORGANIZATION_1` | TechVentures Pvt Ltd |
| `ADDRESS_1` | Flat 5A, MG Road |

**Response shape includes privacy metadata:**
```json
{
  "text": "JARVIS response...",
  "source": "text-only",
  "privacy": {
    "enabled": true,
    "masked": true,
    "detectedCount": 3,
    "detected": ["EMAIL", "PHONE", "PERSON"]
  }
}
```

**Guarantee:** Original PII values are **never** logged or sent to any external API.

## Security Notes

- `.env` files are listed in `.gitignore` — they will **never** be committed to Git
- JWT secrets should be at least 64 random characters
- Never share your `GEMINI_API_KEY`, `SMTP_PASS`, or Twilio credentials
- The Privacy Shield runs **before** every Gemini API call — cannot be bypassed
